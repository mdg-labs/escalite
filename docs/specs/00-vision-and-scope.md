# 00 — Vision & Scope

Escalite is an open-core, self-hostable on-call, alerting, and incident-response platform positioned between GoAlert's reliability model and the UX quality of incident.io and AllQuiet. The doc defines the working name rationale, a competitive gap analysis, and six product pillars: alerting engine, on-call scheduling, incident response, notification delivery, integrations, and status pages. It explicitly scopes MVP to Community Edition only (Phases 0–5 per doc 06), with Cloud as post-MVP, and lists non-goals such as building a full observability stack or ChatOps framework. Target users are platform/SRE teams at 10–500 person orgs and MSPs; v1 success criteria include GoAlert parity for alerting/scheduling, incident timeline + postmortem, mobile push with iOS Critical Alerts, `docker compose up` deployment, and migration importers.
